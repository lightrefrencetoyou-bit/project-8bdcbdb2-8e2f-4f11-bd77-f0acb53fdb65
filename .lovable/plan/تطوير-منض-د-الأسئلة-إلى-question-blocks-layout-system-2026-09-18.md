# تطوير منضّد الأسئلة إلى Question Blocks + Layout System

## النتيجة
نقل مشروع **منصة الأستاذ** من المستودع المشار إليه، ثم استبدال محرر الصفحة النصي الحالي بمحرر كتل أسئلة يحافظ على تصميم الموقع العربي وخطوط صفحة إنشاء الشهادات.

## ما سيتم بناؤه
- تحويل كل سؤال إلى كتلة مستقلة قابلة للتحديد بإطار واضح عند الضغط.
- تحرير نص السؤال مباشرة داخل الورقة مع دعم **عريض، مائل، وتحته خط**.
- شريط تنسيق للسؤال المحدد: نوع الخط، حجم الخط، والمحاذاة يمين/وسط/يسار.
- سحب الكتل وإفلاتها لإعادة ترتيب الأسئلة، مع أزرار ترتيب بديلة للأجهزة اللمسية.
- إضافة وحذف ونسخ كتل الأسئلة، مع ترقيم تلقائي يحافظ على الترتيب الجديد.
- رفع صور وإضافتها إلى ورقة الامتحان ككتل مستقلة قابلة للتحديد والسحب وإعادة الترتيب، مع التحكم بحجمها ومحاذاتها.
- نظام تخطيط للورقة يدعم عموداً واحداً أو عمودين، مع بقاء الرأس والتذييل والتصدير PDF/PNG.
- استعمال قائمة الخطوط نفسها في إنشاء الشهادات: Cairo وTajawal وAmiri وReem Kufi وAref Ruqaa وNoto Kufi Arabic، إضافة إلى الخطوط التي رفعها المستخدم في صفحة الخطوط.

## التفاصيل التقنية
- اعتماد نموذج بيانات موحّد للكتل النصية والصور بدلاً من حفظ HTML كامل لكل صفحة.
- إبقاء التعديل والسحب داخل المتصفح دون إضافة تخزين خلفي.
- استخدام أدوات السحب الأصلية للمتصفح مع مؤشرات مرئية لموضع الإفلات، لتجنب إضافة مكتبة ثقيلة.
- المحافظة على هيكل المشروع الحالي وصفحة `/tools/exam-builder` وتوافق التصدير الحالي.
- إضافة بيانات المشاركة الخاصة بالصفحة المطلوبة (`og:type` و`twitter:card`) إن كانت ناقصة.

## التحقق
- فحص تحديد السؤال والتحرير المباشر والتنسيق والسحب وإعادة الترتيب.
- فحص إضافة صورة وتغيير حجمها ومحاذاتها.
- فحص العمود الواحد والعمودين والتصدير.
- اختبار الصفحة على قياس سطح المكتب والهاتف والتأكد من عدم وجود أخطاء تشغيل أو بناء.
